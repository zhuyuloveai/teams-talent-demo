# qa-regression-selection 技能

## 概述

本技能用于智能选择回归测试范围，在质量与效率间取得平衡。

## 工作流

1. 变更分析：变更描述、代码diff、缺陷清单
2. 影响分析：受影响的功能模块、接口、数据、业务流程
3. 风险评估：按变更类型与影响范围分级（高/中/低）
4. 用例选择：
   - 高风险：全量回归 + 专项测试
   - 中风险：相关模块全量 + 核心冒烟
   - 低风险：相关功能点 + 冒烟
5. 用例优先级排序：P0核心先行
6. 回归执行：按选定范围执行
7. 回归报告：执行情况、缺陷、风险评估、上线建议


## 档位切换规则

| 档位 | 触发条件 | 审批要求 |
|------|---------|---------|
| L1 草稿 | 回归范围思路探索、影响分析讨论、Demo 走查 | 无需评审 |
| L2 标准（默认） | 银行生产默认档，缺陷修复后/需求变更后/版本发布前回归选择 | 测试评审会 + QA负责人签字 |
| L3 实施级 | 涉及资金安全/监管报送/跨系统集成/首次上线/高风险变更 | ARB/合规评审 + 深度门禁全通过 |

**自动升 L3 场景**：涉及反洗钱、限额参数、客户资金、监管报送、跨行接口、生产数据变更、资金冲正/幂等逻辑变更、核心账务模块变更时，自动从 L2 升 L3；L3 须通过下方「深度档位（L3 实施级）」章节的全部可计算门禁。

## 深度档位（L3 实施级）

| 档位 | 要求 |
|------|------|
| L1 | 骨架要点，用于讨论 |
| L2 | 标准评审级（银行生产默认） |
| L3 | 在L2基础上增加以下深度内容（高风险/监管/复杂集成时必用） |

### L3 工作流补充

- 回归基于代码diff影响分析+风险分级选择用例，由 impact_analyzer.py 与 testcase_selector.py 自动辅助
- 影响分析覆盖代码/功能/接口/数据四维度，每维度有受影响清单与用例映射
- 风险分级（高/中/低）有判定规则：高风险=资金/账务/权限模块变更，中风险=业务逻辑变更，低风险=UI/配置变更
- 高风险变更不缩减范围：全量回归+专项测试，由 testcase_selector.py 输出全量用例
- 回归报告含风险评估与上线建议：风险等级、残留风险、上线/延期/回滚建议
- 回归用例集标注基线版本与优先级（P0核心先行），回归范围与变更影响可追溯

### L3 质量门禁

- [ ] 影响分析覆盖四维度（代码/功能/接口/数据，impact_analyzer.py 输出完整）
- [ ] 风险分级有判定规则（高/中/低，资金/账务/权限模块为高风险）
- [ ] 高风险变更不缩减范围（testcase_selector.py 输出全量用例）
- [ ] 用例选择有据可依（影响模块↔用例映射可追溯）
- [ ] 回归用例集标注基线版本与优先级（P0核心先行）
- [ ] 回归报告含风险评估与上线建议（风险等级/残留风险/上线建议）
- [ ] 回归范围与变更影响可追溯（变更文件↔影响模块↔用例）

## 常见失败模式

| 失败模式 | 表现 | 规避措施 | 重试策略 |
|---------|------|---------|---------|
| 遗漏影响范围 | 变更文件未匹配到受影响模块 | 影响分析四维度交叉验证（impact_analyzer.py + 模块映射） | 补充模块映射后重跑 impact_analyzer.py |
| 回归范围过大 | 低风险变更选择全量回归 | 风险分级+精准化用例选择（testcase_selector.py） | 按风险分级重新选择用例 |
| 高风险缩减范围 | 高风险变更未执行全量回归 | 高风险不缩减门禁（testcase_selector.py 输出全量） | 重新选择全量用例后重审 |
| 风险分级无规则 | 风险等级判定主观无依据 | 风险分级判定规则（资金/账务/权限为高风险） | 按规则重新分级后重审 |
| 用例选择无据 | 选定用例无法追溯至影响模块 | 影响模块↔用例映射可追溯 | 补充映射关系后重审 |
| 回归报告无上线建议 | 报告缺风险评估与上线/延期/回滚建议 | 回归报告模板强制上线建议字段 | 补充上线建议后重审 |
| 回归无基线版本 | 回归用例未标注基线版本与优先级 | 回归用例模板强制基线版本字段 | 补充基线版本后重审 |

## 升级路径

| 升级方向 | 触发条件 | 增量字段 | 回退条件 |
|---------|---------|---------|---------|
| L1 → L2 | 进入正式回归选择 | 全部【L2必填】章节（变更分析/影响分析/风险评估/用例选择/回归执行/回归报告） | 评审退回，降为草稿 |
| L2 → L3 | 资金安全/监管报送/跨系统集成/首次上线 | 影响分析四维度、风险分级判定规则、高风险不缩减、用例映射可追溯、基线版本、上线建议 | 风险降级或场景简化，经合规确认可回 L2 |

**人工兜底点**：L3 的风险分级判定与上线建议须由 QA 负责人与 PM 共同确认；Agent 起草，QA 负责人确认后定稿。降级须经 PM + 合规审批并记录原因。
