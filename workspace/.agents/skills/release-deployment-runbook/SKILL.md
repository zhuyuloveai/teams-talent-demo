# release-deployment-runbook 技能

## 概述

本技能用于生成标准化、可复核、可回滚的部署操作手册。

## 工作流

1. 基于发布计划生成详细部署步骤
2. 每个步骤包含：操作/命令/预期结果/验证方法/责任人
3. 前置检查与后置验证步骤
4. 异常处理与应急联系方式
5. 步骤级操作记录模板


## 档位切换规则

| 档位 | 触发条件 | 审批要求 |
|------|---------|---------|
| L1 草稿 | 部署手册思路对齐、步骤讨论、Demo 走查 | 无需评审 |
| L2 标准（默认） | 银行生产默认档，发布执行前部署手册编制 | 运维负责人签字 |
| L3 实施级 | 涉及资金安全/监管报送/跨系统集成/首次上线/重大变更 | ARB/CAB评审 + 深度门禁全通过 |

**自动升 L3 场景**：部署涉及反洗钱、限额参数、客户资金、跨行接口、生产数据变更、首次上线、监管报送窗口、重大架构变更时，自动从 L2 升 L3；L3 须通过下方「深度档位（L3 实施级）」章节的全部可计算门禁。


## 深度档位（L3 实施级）

| 档位 | 要求 |
|------|------|
| L1 | 骨架要点，用于讨论 |
| L2 | 标准评审级（银行生产默认） |
| L3 | 在L2基础上增加以下深度内容（高风险/监管/复杂集成时必用） |

### L3 工作流补充

- L3部署手册每步含操作/命令/预期/验证/责任人
- 前置检查与后置验证量化
- 每步含回退触发条件：当该步验证失败时，明确回退到哪一步及执行哪些回退命令
- 灰度策略与发布计划对齐：每批灰度后须执行后置验证（业务指标+技术指标），未通过则触发回退
- 环境一致性确认：部署目标环境与SIT/UAT环境配置一致（env_diff.py通过），避免环境漂移导致部署失败
- 监控指标与告警阈值与发布计划一致：部署期间关键指标（错误率/TPS/P95）实时监控，超阈值告警
- 每步含操作记录模板（命令输出/执行时间/操作人/异常日志），支撑事后审计
- 应急联系人与升级路径明确：每类异常有对应责任人+联系方式+响应时限（≤15分钟）

### L3 质量门禁

- [ ] 每步含命令级操作与预期结果
- [ ] 每步含回退触发条件与回退命令
- [ ] 前置检查量化（资源水位/依赖服务可用性/配置一致性）
- [ ] 后置验证量化（业务指标+技术指标阈值）
- [ ] 灰度每批有后置验证与回退触发
- [ ] 应急联系人+响应时限（≤15分钟）明确
- [ ] runbook_validator.py 退出码 0（前置/步骤/后置/异常/操作/验证齐全）

> 主模板含【L3必填】深度字段：`templates/deployment-runbook-template.md`；详细档位定义见《Skill深度分级规范》。

## 常见失败模式

| 失败模式 | 表现 | 规避措施 | 重试策略 |
|---------|------|---------|---------|
| 步骤粒度太粗 | 步骤仅写"部署服务"，无具体命令 | 强制命令级细节（含完整命令与参数） | 改写为命令级后重审 |
| 遗漏验证 | 无后置验证或验证不可量化 | 模板强制后置验证+量化阈值 | 补齐量化验证后重审 |
| 回退触发缺失 | 步骤失败后无明确回退路径 | 每步含回退触发条件与回退命令 | 补齐回退路径后重审 |
| 环境不一致 | 生产环境与SIT/UAT配置漂移 | env_diff.py校验+IaC | 修复环境一致性后重试 |
| 监控缺失 | 部署期间无实时监控 | 监控指标与发布计划对齐+告警阈值 | 补齐监控后重审 |
| 应急联系不清 | 异常无责任人或响应慢 | 应急联系人+响应时限≤15分钟 | 补齐联系人后重审 |
| 操作记录缺失 | 步骤执行后无审计证据 | 每步含操作记录模板（命令/时间/操作人） | 补齐记录模板后重审 |

## 升级路径

| 升级方向 | 触发条件 | 增量字段 | 回退条件 |
|---------|---------|---------|---------|
| L1 → L2 | 进入正式发布执行准备 | 全部【L2必填】章节（步骤/命令/验证/异常/责任人） | 评审退回，降为草稿 |
| L2 → L3 | 资金安全/监管报送/跨系统/首次上线 | 回退触发条件+灰度后置验证+环境一致性+监控指标+操作记录模板+应急响应时限 | 风险降级或变更简化，经CAB确认可回 L2 |

**人工兜底点**：L3 的回退触发条件与环境一致性确认须由运维负责人与发布负责人共同确认；Agent 起草部署手册，运维负责人确认后定稿。降级须经 CAB + ARB 审批并记录原因。
