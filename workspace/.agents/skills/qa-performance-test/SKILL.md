# qa-performance-test 技能

## 概述

本技能用于系统化实施性能测试并验证性能指标。

## 工作流

1. 性能需求分析：指标（响应时间/TPS/并发/资源）与场景模型
2. 测试计划：范围、环境、数据、工具、进度、风险
3. 场景设计：基准/负载/压力/稳定性/并发
4. 脚本开发：参数化、关联、断言
5. 测试执行：准备→预热→加压→稳态→采集
6. 结果分析（perf_result_analyzer.py）：TPS、响应、错误率、资源、瓶颈
7. 性能调优：定位瓶颈→方案→验证
8. 性能报告：结论、指标达成、瓶颈、建议、风险


## 档位切换规则

| 档位 | 触发条件 | 审批要求 |
|------|---------|---------|
| L1 草稿 | 性能测试思路探索、场景模型讨论、Demo 走查 | 无需评审 |
| L2 标准（默认） | 银行生产默认档，性能测试需求与性能验收 | 性能评审会 + QA负责人签字 |
| L3 实施级 | 涉及资金安全/监管报送/跨系统集成/首次上线/高风险变更 | ARB/合规评审 + 深度门禁全通过 |

**自动升 L3 场景**：涉及反洗钱、限额参数、客户资金、监管报送、跨行接口、生产数据变更、资金冲正/幂等高并发场景、核心账务系统高并发压测时，自动从 L2 升 L3；L3 须通过下方「深度档位（L3 实施级）」章节的全部可计算门禁。

### L3 工作流补充

- 输出性能场景（基准/负载/压力/稳定性/并发五类）+结果分析，由 perf_result_analyzer.py 与 load_model_gen.py 自动辅助
- 性能基线含三项量化指标：P95响应时间、TPS、错误率（<0.1%），由 perf_result_analyzer.py 与目标对比
- 负载模型由 load_model_gen.py 按场景比例与目标TPS生成，各场景TPS分配合理
- 瓶颈定位有证据：资源使用率（CPU/内存/IO/网络）、慢查询、线程阻塞、GC日志
- 结果可复现：控制变量+多次取均值，环境配置与生产比例折算记录
- 性能报告含调优建议与风险评估：瓶颈定位、调优方案、验证结果、残留风险

### L3 质量门禁

- [ ] 性能场景覆盖五类（基准/负载/压力/稳定性/并发）
- [ ] 性能基线三项量化指标齐全（P95响应时间/TPS/错误率<0.1%）
- [ ] 负载模型由 load_model_gen.py 生成且各场景TPS分配合理
- [ ] 结果分析由 perf_result_analyzer.py 完成且 verdict 为 PASS
- [ ] 瓶颈定位有证据（资源使用率/慢查询/线程阻塞/GC日志）
- [ ] 结果可复现（控制变量+多次取均值+环境折算记录）
- [ ] 性能报告含调优建议与风险评估（瓶颈/方案/验证/残留风险）

## 常见失败模式

| 失败模式 | 表现 | 规避措施 | 重试策略 |
|---------|------|---------|---------|
| 环境与生产差异大 | 性能数据无法代表生产真实情况 | 环境比例评估+折算+配置对齐 | 调整环境配置后重测 |
| 结果不可复现 | 多次执行数据波动大 | 控制变量+多次取均值+环境预热 | 预热后多次执行取均值 |
| 调优无方向 | 瓶颈定位无证据，盲目调优 | 分层瓶颈定位（资源/慢查询/线程/GC） | 补充监控证据后重新定位 |
| 性能场景遗漏 | 缺基准/负载/压力/稳定性/并发某类 | 五类场景checklist强制覆盖 | 补充缺失场景后重测 |
| 性能基线无量化 | P95/TPS/错误率无目标值 | 性能基线三指标门禁（P95/TPS/错误率<0.1%） | 补充量化目标后重测 |
| 负载模型不合理 | 各场景TPS分配与业务比例不符 | load_model_gen.py 按场景比例生成 | 修正场景比例后重生成模型 |
| 结果未达标未处理 | perf_result_analyzer.py 判定FAIL仍上线 | verdict=PASS 门禁 + 调优后重测 | 调优后重跑至 PASS |

## 升级路径

| 升级方向 | 触发条件 | 增量字段 | 回退条件 |
|---------|---------|---------|---------|
| L1 → L2 | 进入正式性能测试 | 全部【L2必填】章节（需求分析/测试计划/场景设计/脚本开发/测试执行/结果分析/性能报告） | 评审退回，降为草稿 |
| L2 → L3 | 资金安全/监管报送/跨系统集成/首次上线 | 五类性能场景、性能基线三指标、负载模型自动生成、瓶颈定位证据、结果可复现、调优建议与风险评估 | 风险降级或场景简化，经合规确认可回 L2 |

**人工兜底点**：L3 的性能基线指标与调优方案须由 QA 性能专家与架构师共同确认；Agent 起草，性能专家确认后定稿。降级须经 PM + 合规审批并记录原因。
