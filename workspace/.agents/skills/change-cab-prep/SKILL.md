# change-cab-prep 技能

## 概述

本技能用于自动收集并整理CAB评审材料，确保评审高效、信息充分。

## 工作流

1. 按CAB材料清单收集各项产出
2. 检查材料完整性（cab_material_check.py）
3. 生成CAB评审包（摘要+详情）
4. 识别评审重点与风险点
5. 提前发送给CAB成员


## 档位切换规则

| 档位 | 触发条件 | 审批要求 |
|------|---------|---------|
| L1 草稿 | 材料预收集、CAB议程草拟、Demo走查 | 无需评审 |
| L2 标准（默认） | 银行生产默认档，常规变更CAB评审前材料准备 | 变更经理审核 + CAB召集人确认 |
| L3 实施级 | 高风险变更/监管报送/跨系统集成/首次上线/紧急变更补审 | ARB/合规评审 + 深度门禁全通过 |

**自动升 L3 场景**：涉及反洗钱、限额参数、客户资金、监管报送、跨行接口、生产数据变更、紧急变更（紧急通道上线）时，自动从 L2 升 L3；L3 须通过下方「深度档位（L3 实施级）」章节的全部可计算门禁。

## 深度档位（L3 实施级）

| 档位 | 要求 |
|------|------|
| L1 | 骨架要点，用于讨论 |
| L2 | 标准评审级（银行生产默认） |
| L3 | 在L2基础上增加以下深度内容（高风险/监管/复杂集成时必用） |

### L3 工作流补充

- L3 CAB材料按清单逐项+摘要突出风险点与决策项
- 提前送达时间合规
- 每份RFC/风险评估/回滚方案须在材料包中标注版本号、签字人与最近更新时间，便于CAB追溯
- 评审包须包含本次变更的影响评估结论（受影响系统/接口/数据/客户数）与回退预案可行性证据（回退步骤演练通过、回退时长上限）
- 高风险/紧急变更须附独立应急通讯录（值班电话/二线/三线/厂商热线）与升级路径图，CAB可一键触达
- CAB评审留痕：议程、出席人签到、表决记录、决议事项、待跟进项须结构化输出（评审纪要模板），可被审计追溯
- 窗口冲突前置检测：评审包中须明确本次窗口与同期其他变更/业务活动/冻结期是否冲突，冲突项标注处置方案

### L3 质量门禁

- [ ] cab_material_check.py 退出码 0（六类材料齐全：RFC/风险评估/回滚/测试/影响分析/发布计划）
- [ ] 每份材料含版本号、签字人、最近更新时间（可机器扫描）
- [ ] 评审包含影响评估结论（受影响系统/接口/数据条数）与回退可行性证据（演练通过/回退时长上限）
- [ ] 高风险/紧急变更附应急通讯录与升级路径图
- [ ] CAB评审纪要含出席签到、表决记录、决议事项、待跟进项（结构化字段）
- [ ] 窗口冲突检测结果明确（冲突项 + 处置方案）
- [ ] 评审包送达时间 ≥ CAB会议前24小时（紧急变更 ≥ 2小时并标注紧急通道）

> 主模板含【L3必填】深度字段：`templates/cab-package-template.md`；详细档位定义见《Skill深度分级规范》。

## 常见失败模式

| 失败模式 | 表现 | 规避措施 | 重试策略 |
|---------|------|---------|---------|
| 材料缺失 | cab_material_check.py 报 missing 项 | 清单式检查 + 提前催交（T-48h提醒） | 补齐缺失材料后重跑脚本，退出码=0 才提交 |
| 摘要过长/无重点 | CAB成员反馈抓不到决策项 | 控制摘要 ≤ 2页 + 突出风险点与决策项 | 按"风险点→决策项→备选方案"三段重写摘要 |
| 送达时间违规 | 评审包会议前不足24小时送达 | 流程门禁：T-24h未送达自动告警 | 紧急通道须升级L3并标注，否则改期 |
| 评审无留痕 | 出席/表决/决议无结构化记录 | CAB纪要模板强制字段（签到/表决/决议/待跟进） | 补录纪要并经召集人签字后归档 |
| 影响评估缺失 | 评审包无受影响系统/接口/客户数清单 | 模板强制影响评估章节 + 复用 ba-change-impact 产出 | 引用 ba-change-impact 报告后重提交 |
| 回退预案不可行 | 回退步骤未演练/无时长上限 | 回退演练记录 + 时长上限量化 | 完成回退演练并附证据后重提交 |
| 窗口冲突未检测 | 与同期变更/冻结期重叠 | 评审包附 window_scheduler.py 冲突报告 | 调整窗口或标注冲突处置方案后重提交 |

## 升级路径

| 升级方向 | 触发条件 | 增量字段 | 回退条件 |
|---------|---------|---------|---------|
| L1 → L2 | 进入正式CAB评审流程 | 全部【L2必填】章节（材料清单校验/评审包/摘要/送达时间） | 评审退回，降为草稿 |
| L2 → L3 | 高风险变更/监管报送/跨系统集成/首次上线/紧急变更补审 | 材料版本与签字、影响评估结论、回退可行性证据、应急通讯录、CAB留痕结构化字段、窗口冲突报告 | 风险降级或场景简化，经合规确认可回 L2 |

**人工兜底点**：L3 的回退可行性证据与应急通讯录须由变更经理与运维负责人共同确认；Agent 起草评审包，CAB召集人确认后定稿。降级须经 PM + 合规审批并记录原因。
