# pm-risk-register 技能

## 概述

本技能用于项目全生命周期的风险管理。

## 工作流

1. 持续识别风险（进度/质量/资源/技术/合规/供应商）
2. 风险评估（风险_scorer.py：概率×影响矩阵）
3. 制定应对策略（规避/转移/减轻/接受）
4. 跟踪风险状态与应对进展
5. 定期输出风险报告与预警


## 档位切换规则

| 档位 | 触发条件 | 审批要求 |
|------|---------|---------|
| L1 草稿 | 风险初识别、头脑风暴、思路对齐 | 无需评审 |
| L2 标准（默认） | 银行生产默认档，迭代规划/里程碑前风险登记与跟踪 | PM审核 + 风险条线负责人签字 |
| L3 实施级 | 高风险项目/监管报送项目/跨系统大型项目/首次上线 | ARB/合规评审 + 深度门禁全通过 |

**自动升 L3 场景**：涉及反洗钱、限额参数、客户资金、监管报送、跨行接口、生产数据变更、风险敞口影响客户数 > 1万、风险跨系统依赖 ≥ 3 个时，自动从 L2 升 L3；L3 须通过下方「深度档位（L3 实施级）」章节的全部可计算门禁。

## 深度档位（L3 实施级）

| 档位 | 要求 |
|------|------|
| L1 | 骨架要点，用于讨论 |
| L2 | 标准评审级（银行生产默认） |
| L3 | 在L2基础上增加以下深度内容（高风险/监管/复杂集成时必用） |

### L3 工作流补充

- L3风险登记含概率×影响评分+应对策略+升级路径
- 定期风险报告与预警
- 风险量化：每条风险须含概率（低/中/高）×影响（低/中/高）评分，由 risk_scorer.py 输出等级，人工可调整但须记录理由
- 风险燃尽跟踪：每周更新风险状态（开放/缓解/关闭），输出风险燃尽图（开放风险数随时间变化）
- 升级路径明确：高风险须附升级路径（PM → 风险条线 → ARB → 高管），每级升级触发条件量化（如概率升至"高"或影响客户数 > 1万）
- 应对措施可执行：每条应对措施须含具体步骤、责任人、截止时间、验证标准（如何确认风险已缓解）
- 风险分类覆盖六类：进度/质量/资源/技术/合规/供应商，每类至少识别 1 条风险

### L3 质量门禁

- [ ] 每条风险含概率×影响评分，等级由 risk_scorer.py 输出（人工调整须记录理由）
- [ ] 高风险（等级=高）含升级路径（PM → 风险条线 → ARB → 高管），每级触发条件量化
- [ ] 每条应对措施含具体步骤、责任人、截止时间、验证标准四项
- [ ] 风险分类覆盖六类（进度/质量/资源/技术/合规/供应商），每类 ≥ 1 条
- [ ] 风险燃尽图每周更新（开放风险数随时间变化可追溯）
- [ ] 风险登记册可按风险ID追溯到需求/变更/测试用例
- [ ] 高风险风险有独立应急计划（值班通讯录 + BCP + 客户公告模板）

## 常见失败模式

| 失败模式 | 表现 | 规避措施 | 重试策略 |
|---------|------|---------|---------|
| 风险识别不全 | 六类风险有类别空缺 | 按类别清单逐项检查（进度/质量/资源/技术/合规/供应商） | 补全缺失类别风险后重提交 |
| 应对措施空泛 | 仅写"加强监控"，无步骤/责任人/截止 | 强制四项字段（步骤/责任人/截止/验证标准） | 补全四项字段后重提交 |
| 评分缺失 | 风险无概率×影响评分 | risk_scorer.py 强制评分 | 调用脚本评分后重提交 |
| 升级路径缺失 | 高风险无升级路径或触发条件未量化 | 模板强制升级路径字段（PM→风险条线→ARB→高管） | 补全升级路径与触发条件后重提交 |
| 燃尽图未更新 | 风险状态停滞，无周度更新 | 流程门禁：每周五自动催更 | 补更风险状态并更新燃尽图 |
| 风险不可追溯 | 风险ID未关联需求/变更/测试 | 风险ID关联字段必填 | 补全关联后重提交 |
| 应急计划缺失 | 高风险无值班通讯录/BCP | L3强制应急计划章节 | 补全应急计划后重提交 |

## 升级路径

| 升级方向 | 触发条件 | 增量字段 | 回退条件 |
|---------|---------|---------|---------|
| L1 → L2 | 进入迭代规划/里程碑前风险登记 | 全部【L2必填】章节（风险识别/评分/应对策略/跟踪状态/风险报告） | 评审退回，降为草稿 |
| L2 → L3 | 高风险项目/监管报送/跨系统大型项目/首次上线 | 风险量化评分、升级路径量化、应对措施四项字段、六类覆盖、风险燃尽图、追溯链、应急计划 | 风险降级或场景简化，经合规确认可回 L2 |

**人工兜底点**：L3 的风险量化评分与升级路径须由 PM 与风险条线负责人共同确认；Agent 起草风险登记册，风险条线负责人确认后定稿。降级须经 PM + 合规审批并记录原因。
