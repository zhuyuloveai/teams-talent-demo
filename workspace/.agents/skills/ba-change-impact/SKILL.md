# ba-change-impact 技能

## 概述

本技能用于评估需求变更的影响范围与工作量变化，输出变更评估意见。

## 工作流

1. 读取原需求与变更描述
2. 识别差异点（功能/范围/规则/接口）
3. 分析受影响的故事/用例/设计/测试
4. 评估工作量变化与进度影响
5. 输出变更评估报告与建议


## 档位切换规则

| 档位 | 触发条件 | 审批要求 |
|------|---------|---------|
| L1 草稿 | 变更影响初评、思路对齐、Demo走查 | 无需评审 |
| L2 标准（默认） | 银行生产默认档，收到变更请求时常规影响评估 | BA负责人审核 + PM确认 |
| L3 实施级 | 高风险变更/监管报送/跨系统集成/首次上线/影响客户资金 | ARB/合规评审 + 深度门禁全通过 |

**自动升 L3 场景**：涉及反洗钱、限额参数、客户资金、监管报送、跨行接口、生产数据变更、影响客户数 > 1万、跨系统依赖 ≥ 3 个时，自动从 L2 升 L3；L3 须通过下方「深度档位（L3 实施级）」章节的全部可计算门禁。

## 深度档位（L3 实施级）

| 档位 | 要求 |
|------|------|
| L1 | 骨架要点，用于讨论 |
| L2 | 标准评审级（银行生产默认） |
| L3 | 在L2基础上增加以下深度内容（高风险/监管/复杂集成时必用） |

### L3 工作流补充

- L3影响评估覆盖功能/数据/接口/进度/成本/干系人六维并附证据
- 工作量估算给出区间与依据（参考历史同类变更）
- 变更影响范围量化：受影响功能模块数、用户故事数、测试用例数、接口数、数据表数、客户数六项可计算
- 影响项分类分级：每条影响项须分类（新增/修改/删除）与分级（高/中/低），分级依据影响客户数与资金风险
- 工作量估算区间：须给最小值/最可能值/最大值三值，并引用历史同类变更的实际工时数据
- 进度影响量化：须说明对当前迭代/里程碑的影响（延期天数、门禁通过概率）
- 干系人影响：须列出受影响干系人（业务/运维/合规/供应商）与通知方式

### L3 质量门禁

- [ ] 六维影响全覆盖（功能/数据/接口/进度/成本/干系人）
- [ ] 每条影响有证据引用（需求ID/故事ID/用例ID/接口ID/数据表名）
- [ ] 变更影响范围量化（模块数/故事数/用例数/接口数/数据表数/客户数六项）
- [ ] 影响项分类（新增/修改/删除）与分级（高/中/低）齐全
- [ ] 工作量估算给三值（最小/最可能/最大）并引用历史同类变更数据
- [ ] 进度影响量化（延期天数、门禁通过概率）
- [ ] 干系人影响列出（业务/运维/合规/供应商）与通知方式

## 常见失败模式

| 失败模式 | 表现 | 规避措施 | 重试策略 |
|---------|------|---------|---------|
| 影响评估不全面 | 六维有缺失（如遗漏干系人/数据维度） | 模板强制六维检查（功能/数据/接口/进度/成本/干系人） | 补全缺失维度后重提交 |
| 影响范围未量化 | 仅写"影响较大"，无模块数/故事数/客户数 | 模板强制六项量化字段 | 补全量化数据后重提交 |
| 证据引用缺失 | 影响项无需求ID/故事ID/用例ID | 每条影响必填证据引用字段 | 补全证据引用后重提交 |
| 估算单值无区间 | 仅给一个工时数，无三值/历史依据 | 强制三值（最小/最可能/最大）+ 历史引用 | 补全三值与历史依据后重提交 |
| 影响项未分类分级 | 影响项无新增/修改/删除分类，无高/中/低分级 | 模板强制分类分级字段 | 补全分类分级后重提交 |
| 进度影响未量化 | 仅写"可能延期"，无延期天数/门禁概率 | 进度影响量化字段（延期天数/门禁通过概率） | 补全进度量化后重提交 |
| 干系人通知遗漏 | 未列出受影响干系人与通知方式 | 干系人章节强制四类（业务/运维/合规/供应商） | 补全干系人与通知方式后重提交 |

## 升级路径

| 升级方向 | 触发条件 | 增量字段 | 回退条件 |
|---------|---------|---------|---------|
| L1 → L2 | 收到变更请求，进入正式影响评估 | 全部【L2必填】章节（差异识别/受影响项分析/工作量估算/评估报告） | 评审退回，降为草稿 |
| L2 → L3 | 高风险变更/监管报送/跨系统集成/首次上线/影响客户资金 | 六维覆盖、影响范围六项量化、影响项分类分级、估算三值+历史依据、进度量化、干系人四类 | 风险降级或场景简化，经合规确认可回 L2 |

**人工兜底点**：L3 的影响范围量化与工作量估算须由 BA 与业务负责人共同确认；Agent 起草评估报告，BA 负责人确认后定稿。降级须经 PM + 合规审批并记录原因。
