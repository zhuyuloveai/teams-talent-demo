# dev-refactoring 技能

## 概述

本技能用于识别重构机会并辅助安全重构，保证重构不改变功能。

## 工作流

1. 分析代码坏味道与技术债（debt_scanner.py）
2. 识别重构机会与优先级
3. 制定重构计划（小步、可验证、不改变功能）
4. 生成重构方案与测试策略
5. 重构后验证功能一致性（单测+对比测试）

## 档位切换规则

| 档位 | 触发条件 | 审批要求 |
|------|---------|---------|
| L1 草稿 | 重构机会初判、技术债评估草案、方案讨论 | 无需评审 |
| L2 标准（默认） | 银行生产默认档，技术债清理、功能重构、代码质量提升 | 重构评审 + 技术负责人签字 |
| L3 实施级 | 涉及资金安全/监管报送/跨系统集成/首次上线/高风险变更 | ARB/合规评审 + 深度门禁全通过 |

**自动升 L3 场景**：涉及资金类核心逻辑重构（转账/支付/清算/限额）、监管报送代码、跨服务接口契约变更、生产数据访问层重构时，自动从 L2 升 L3；L3 须通过下方「深度档位（L3 实施级）」章节的全部可计算门禁。

## 深度档位（L3 实施级）

| 档位 | 要求 |
|------|------|
| L1 | 骨架要点，用于讨论 |
| L2 | 标准评审级（银行生产默认） |
| L3 | 在L2基础上增加以下深度内容（高风险/监管/复杂集成时必用） |

### L3 工作流补充

- L3重构计划含小步验证、行为等价测试与技术债量化
- 重构前后指标对比（复杂度/重复/覆盖）
- 字段级行为保持：资金计算（精度/溢出/正负）、状态机（状态流转/防重复）、幂等性（幂等键/重复响应）逐字段验证重构前后行为等价
- 异常路径等价：原异常路径（超时/重试/熔断/降级/补偿）在新代码中行为一致，错误码与响应不变
- 事务边界保持：原事务边界、隔离级别、补偿路径在新代码中一致，不引入跨服务事务或分布式事务风险
- 并发安全保持：原锁策略、并发度、线程安全保证在新代码中一致，不引入竞态或死锁
- 回滚方案：重构可分步回滚，每步独立可验证，资金类重构须含生产回滚预案与数据修复脚本

### L3 质量门禁

- [ ] 功能等价（重构前后单测+对比测试全通过）
- [ ] 技术债指标改善（debt_scanner.py large_files 减少/复杂度下降）
- [ ] 重构范围受控（每步变更 < 500 行，可独立合并）
- [ ] 字段级行为等价（资金/状态机/幂等逐字段验证）
- [ ] 异常路径等价（错误码/响应/降级策略不变）
- [ ] 事务与并发安全保持（事务边界/锁策略一致）
- [ ] 回滚方案就绪（分步回滚+生产数据修复脚本）

## 常见失败模式

| 失败模式 | 表现 | 规避措施 | 重试策略 |
|---------|------|---------|---------|
| 重构范围蔓延 | 一次改太多，无法独立合并/回滚 | 严格按计划控制 + 每步 < 500 行 | 拆分小步后重审 |
| 引入新 bug | 重构改动破坏功能 | 强制单测+对比测试 | 回退后补测试再重构 |
| 行为不等价 | 资金计算精度/状态机流转变化 | L3 字段级行为等价验证 | 回退后逐字段比对再重构 |
| 异常路径变化 | 错误码/降级策略/补偿路径改变 | L3 异常路径等价检查 | 回退后补异常路径测试 |
| 事务边界变化 | 事务范围扩大/隔离级别改变 | L3 事务边界保持检查 | 回退后对齐事务设计 |
| 并发安全问题 | 锁策略变化引发竞态/死锁 | L3 并发安全保持 + 并发单测 | 回退后补并发单测 |
| 无回滚方案 | 生产重构失败无法回退 | 分步回滚 + 数据修复脚本 | 补回滚方案后再上线 |

## 升级路径

| 升级方向 | 触发条件 | 增量字段 | 回退条件 |
|---------|---------|---------|---------|
| L1 → L2 | 进入正式重构/重构评审 | 重构计划、小步拆分、测试策略、技术债评估 | 评审退回，降为草稿 |
| L2 → L3 | 资金安全/监管报送/跨系统集成/首次上线 | 字段级行为等价、异常路径等价、事务与并发保持、回滚方案与数据修复脚本 | 风险降级或场景简化，经合规确认可回 L2 |

**人工兜底点**：L3 的字段级行为等价与回滚方案须由技术委员会与架构师共同确认；Agent 起草，架构师确认后定稿。降级须经 PM + 合规审批并记录原因。
