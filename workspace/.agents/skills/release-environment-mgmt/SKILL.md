# release-environment-mgmt 技能

## 概述

本技能用于管理多套环境并检测配置漂移。

## 工作流

1. 环境配置清单维护（软件版本/参数/中间件）
2. 环境一致性检查（env_diff.py）
3. 环境申请与交付流程支持
4. 环境问题诊断辅助
5. 配置变更的版本控制


## 档位切换规则

| 档位 | 触发条件 | 审批要求 |
|------|---------|---------|
| L1 草稿 | 环境清单初步梳理、配置差异探索、内部沟通 | 无需评审 |
| L2 标准（默认） | 银行生产默认档，环境准备与配置变更管理 | 运维负责人签字 |
| L3 实施级 | 涉及资金安全/监管报送/跨系统集成/首次上线/生产环境变更 | ARB/CAB评审 + 深度门禁全通过 |

**自动升 L3 场景**：环境变更涉及反洗钱、限额参数、客户资金、跨行接口、生产数据访问、监管报送字段、生产环境核心配置（数据库/中间件/网络）时，自动从 L2 升 L3；L3 须通过下方「深度档位（L3 实施级）」章节的全部可计算门禁。


## 深度档位（L3 实施级）

| 档位 | 要求 |
|------|------|
| L1 | 骨架要点，用于讨论 |
| L2 | 标准评审级（银行生产默认） |
| L3 | 在L2基础上增加以下深度内容（高风险/监管/复杂集成时必用） |

### L3 工作流补充

- L3输出环境清单+配置差异报告+变更版本化
- 漂移自动扫描
- 环境一致性矩阵：DEV/SIT/UAT/PROD/DR 五套环境的软件版本/参数/中间件配置逐项对比，差异项须有变更说明与审批记录
- 配置漂移自动扫描：每日定时运行 env_diff.py，发现漂移自动告警并生成修复工单
- 配置变更版本化：所有环境配置纳入 Git 仓库（IaC），变更须走 PR 评审，禁止手工改配置
- 环境可用性监控：每套环境的健康检查（端口/服务/数据库连接）纳入监控，异常告警
- 生产环境变更须有回退方案：变更失败时可在15分钟内回退到上一版本配置
- DR 环境与 PROD 环境配置同步：DR 须能在 RTO（≤4小时）内接管，定期演练验证

### L3 质量门禁

- [ ] 五套环境（DEV/SIT/UAT/PROD/DR）配置清单完整
- [ ] env_diff.py 退出码 0（无配置漂移）
- [ ] 配置变更全部纳入 Git 版本控制（IaC）
- [ ] 配置漂移每日扫描且有告警闭环
- [ ] 环境可用性监控覆盖（端口/服务/数据库）
- [ ] 生产环境变更有回退方案（≤15分钟回退）
- [ ] DR 环境与 PROD 同步且有演练记录（RTO≤4小时）

## 常见失败模式

| 失败模式 | 表现 | 规避措施 | 重试策略 |
|---------|------|---------|---------|
| 配置漂移 | 生产环境被手工修改，与清单不符 | env_diff.py每日扫描+IaC+告警闭环 | 修复漂移并重跑脚本后重试 |
| 环境不一致 | SIT/UAT/PROD 配置差异未记录 | 五套环境一致性矩阵+差异说明 | 补齐差异说明后重审 |
| 变更未版本化 | 配置变更未入 Git，无法追溯 | IaC强制+PR评审+禁止手工改 | 将配置纳入Git后重审 |
| 漂移无告警 | 漂移发现滞后，影响发布 | 每日扫描+自动告警+修复工单 | 配置告警闭环后重试 |
| 可用性盲区 | 环境健康检查未纳入监控 | 端口/服务/数据库监控全覆盖 | 补齐监控后重审 |
| 回退方案缺失 | 生产变更失败无法快速回退 | 强制回退方案+≤15分钟回退能力 | 补齐回退方案后重审 |
| DR不同步 | DR环境配置滞后，无法RTO内接管 | DR与PROD同步+定期演练(RTO≤4h) | 同步配置并演练后重审 |

## 升级路径

| 升级方向 | 触发条件 | 增量字段 | 回退条件 |
|---------|---------|---------|---------|
| L1 → L2 | 进入正式环境管理 | 全部【L2必填】章节（环境清单/一致性检查/变更记录） | 评审退回，降为草稿 |
| L2 → L3 | 资金安全/监管报送/生产环境核心变更 | 五环境一致性矩阵+IaC版本化+漂移告警+可用性监控+回退方案+DR演练 | 风险降级或变更简化，经CAB确认可回 L2 |

**人工兜底点**：L3 的生产环境回退方案与 DR 演练结论须由运维负责人与 DR 负责人共同确认；Agent 起草环境清单与差异报告，运维负责人确认后定稿。降级须经 CAB + ARB 审批并记录原因。
