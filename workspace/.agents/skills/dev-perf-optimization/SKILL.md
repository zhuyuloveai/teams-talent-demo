# dev-perf-optimization 技能

## 概述

本技能用于系统性地分析和优化代码性能。

## 工作流

1. 性能问题定位：瓶颈分析（CPU/内存/IO/网络/数据库）
2. 根因分析：慢查询、内存泄漏、低效算法、资源竞争
3. 优化方案设计：确定方向与预期收益，排优先级
4. 实施优化：代码级 + SQL + 缓存 + 并发
5. 性能验证：基准对比（perf_compare.py）
6. 性能回归：确保无功能退化
7. 输出性能优化报告

## 档位切换规则

| 档位 | 触发条件 | 审批要求 |
|------|---------|---------|
| L1 草稿 | 性能瓶颈初判、优化方案讨论、ROI 评估 | 无需评审 |
| L2 标准（默认） | 银行生产默认档，性能问题修复、优化专项、性能 review | 性能评审 + 性能负责人签字 |
| L3 实施级 | 涉及资金安全/监管报送/跨系统集成/首次上线/高风险变更 | ARB/合规评审 + 深度门禁全通过 |

**自动升 L3 场景**：涉及资金类接口性能（转账/支付/清算 P95 达标）、监管报送时效、高并发场景（大促/月末跑批）、生产性能回退时，自动从 L2 升 L3；L3 须通过下方「深度档位（L3 实施级）」章节的全部可计算门禁。

| 档位 | 要求 |
|------|------|

| L2 | 标准评审级（银行生产默认） |

### L3 工作流补充

- L3输出瓶颈定位证据+优化前后基准对比+回归验证
- 优化收益量化（TPS/P95/资源）
- 字段级性能指标：TPS（min/avg/p95/p99）、延迟（min/avg/p95/p99）、错误率、资源（CPU/内存/IO/连接数）逐指标采集与对比
- 慢查询根因分析：执行计划、索引命中、扫描行数、锁等待、返回行数逐项分析并给出优化建议（slow_query_analyzer.py）
- 并发安全与性能平衡：锁粒度（行锁/表锁/分布式锁）、并发度、连接池大小、线程池大小的取舍与压测验证
- 边界值压测：目标 TPS 的 1x/2x/5x、突增流量、持续运行（疲劳测试）、内存增长曲线逐场景压测
- 异常路径性能：超时重试、熔断降级、限流排队下的性能表现与资源消耗

### L3 质量门禁

- [ ] 收益可量化（perf_compare.py improved=true，TPS 提升/P95 下降有数据）
- [ ] 无功能回归（完整回归测试通过）
- [ ] 指标达标（TPS/P95/错误率达成目标值）
- [ ] 慢查询清零（slow_query_analyzer.py 无慢查询或全部有优化建议）
- [ ] P99 延迟达标（不仅看 P95，长尾延迟覆盖）
- [ ] 边界压测通过（2x/5x 目标 TPS 不崩溃）
- [ ] 资源消耗在阈值内（CPU/内存/连接数不超限）

## 常见失败模式

| 失败模式 | 表现 | 规避措施 | 重试策略 |
|---------|------|---------|---------|
| 过早优化 | 未测量就优化，收益不明 | 先测量后优化 + perf_compare.py 量化 | 回退优化，先建立基线 |
| 过度优化 | ROI 低的优化投入过多精力 | ROI 评估 + 优先级排序 | 砍低 ROI 项后重审 |
| 引入新 bug | 优化改动破坏功能 | 完整回归测试 + 对比测试 | 回退优化后重测 |
| 性能回退 | 上线后 P95 升高/TPS 下降 | 性能基线门禁 + perf_compare.py 回归 | 回退版本后重测 |
| 慢查询遗漏 | 未识别慢查询导致 DB 压力 | slow_query_analyzer.py + 执行计划审查 | 补索引/改 SQL 后重测 |
| 只看 P95 忽略 P99 | 长尾延迟未优化，用户体验差 | L3 要求 P99 达标 | 补 P99 优化后重测 |
| 并发优化引发安全问题 | 锁粒度调小导致竞态/数据错 | 并发单测 + 锁粒度压测验证 | 调回安全锁粒度后重测 |

## 升级路径

| 升级方向 | 触发条件 | 增量字段 | 回退条件 |
|---------|---------|---------|---------|
| L1 → L2 | 进入正式性能优化/性能评审 | 瓶颈定位证据、优化方案、基准对比、回归测试 | 评审退回，降为草稿 |
| L2 → L3 | 资金安全/监管报送/跨系统集成/首次上线 | 字段级性能指标（P99）、边界压测、慢查询根因分析、并发安全验证 | 风险降级或场景简化，经合规确认可回 L2 |

**人工兜底点**：L3 的边界压测结果与并发安全验证须由性能专家与后端架构师共同确认；Agent 起草，性能专家确认后定稿。降级须经 PM + 合规审批并记录原因。
