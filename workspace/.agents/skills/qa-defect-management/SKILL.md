# qa-defect-management 技能

## 概述

本技能用于缺陷全生命周期管理与统计分析。

## 工作流

1. 记录缺陷（步骤/预期/实际/截图/环境）
2. 判定严重级别与优先级（defect_classifier.py）
3. 分配给对应开发跟踪
4. 验证修复并关闭
5. 缺陷统计与趋势分析
6. 评估测试退出的缺陷遗留风险


## 档位切换规则

| 档位 | 触发条件 | 审批要求 |
|------|---------|---------|
| L1 草稿 | 缺陷登记思路探索、分类规则讨论、Demo 走查 | 无需评审 |
| L2 标准（默认） | 银行生产默认档，缺陷生命周期管理与退出评估 | 测试评审会 + QA负责人签字 |
| L3 实施级 | 涉及资金安全/监管报送/跨系统集成/首次上线/高风险变更 | ARB/合规评审 + 深度门禁全通过 |

**自动升 L3 场景**：涉及反洗钱、限额参数、客户资金、监管报送、跨行接口、生产数据变更、资金冲正/幂等缺陷、生产事故复盘时，自动从 L2 升 L3；L3 须通过下方「深度档位（L3 实施级）」章节的全部可计算门禁。

## 深度档位（L3 实施级）

| 档位 | 要求 |
|------|------|
| L1 | 骨架要点，用于讨论 |
| L2 | 标准评审级（银行生产默认） |
| L3 | 在L2基础上增加以下深度内容（高风险/监管/复杂集成时必用） |

### L3 工作流补充

- 缺陷单含完整复现步骤+证据截图/日志+级别判定矩阵，级别由 defect_classifier.py 初判 + 人工复核
- 缺陷分级四档：致命（资金损失/数据丢失/越权）/严重（主流程阻塞）/一般（功能缺陷）/提示（UI/体验），每档有处置时效要求
- 缺陷趋势分析含发现速率/修复速率/积压曲线，预判测试退出时的遗留风险
- 资金类缺陷须触发紧急流程：30分钟内响应、2小时内定位、修复后强制回归
- 测试退出遗留缺陷须有处置计划：致命/严重缺陷0、一般缺陷有修复计划或豁免审批、提示缺陷登记跟踪
- 缺陷根因分析：资金类与严重缺陷须做根因分析（代码/设计/需求/流程），输出改进措施

### L3 质量门禁

- [ ] 缺陷信息完整率100%（复现步骤+证据+环境+版本四要素）
- [ ] 严重级别判定一致率≥90%（defect_classifier.py 初判 + 人工复核）
- [ ] 缺陷分级四档齐全（致命/严重/一般/提示）且处置时效达标
- [ ] 资金类缺陷有紧急流程记录（30分钟响应/2小时定位/强制回归）
- [ ] 测试退出遗留缺陷：致命/严重缺陷0，一般缺陷有处置计划或豁免审批
- [ ] 资金类与严重缺陷有根因分析与改进措施
- [ ] 缺陷闭环率100%（已关闭缺陷均经验证）

## 常见失败模式

| 失败模式 | 表现 | 规避措施 | 重试策略 |
|---------|------|---------|---------|
| 缺陷描述模糊 | 缺复现步骤/证据/环境/版本 | 缺陷单模板强制四要素字段 | 补充四要素后重审 |
| 级别判定不准 | 致命缺陷判为一般或反之 | defect_classifier.py 初判 + 判定矩阵 + 人工复核 | 重新判定级别后重审 |
| 缺陷分级缺失 | 未区分致命/严重/一般/提示四档 | 分级四档模板强制每档处置时效 | 补充分级与时效后重审 |
| 资金类缺陷未走紧急流程 | 资金类缺陷未在30分钟内响应 | 资金类缺陷紧急流程门禁（响应/定位/回归） | 触发紧急流程后重审 |
| 遗留缺陷无处置计划 | 测试退出时一般缺陷无修复计划或豁免 | 退出遗留缺陷处置计划必填（修复计划/豁免审批） | 补充处置计划后重审 |
| 缺陷无根因分析 | 资金/严重缺陷未做根因分析与改进 | 根因分析强制（代码/设计/需求/流程四维） | 补充根因分析后重审 |
| 缺陷未闭环 | 已关闭缺陷未经验证直接关闭 | 闭环验证门禁（验证后才能关闭） | 重新验证后关闭 |

## 升级路径

| 升级方向 | 触发条件 | 增量字段 | 回退条件 |
|---------|---------|---------|---------|
| L1 → L2 | 进入正式缺陷管理 | 全部【L2必填】章节（复现步骤/级别判定/分配跟踪/验证关闭/趋势分析） | 评审退回，降为草稿 |
| L2 → L3 | 资金安全/监管报送/跨系统集成/首次上线 | 分级四档与处置时效、资金类紧急流程、根因分析、遗留缺陷处置计划 | 风险降级或场景简化，经合规确认可回 L2 |

**人工兜底点**：L3 的缺陷级别判定与遗留缺陷豁免审批须由 QA 负责人与业务负责人共同确认；Agent 起草，QA 负责人确认后定稿。降级须经 PM + 合规审批并记录原因。
