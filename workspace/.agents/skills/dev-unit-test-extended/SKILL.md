# dev-unit-test-extended 技能

## 概述

本技能提供分层单测策略、Mock规范与测试质量评估，超越基础单测生成。

## 工作流

1. 分析代码结构，确定单测范围与粒度（测试金字塔）
2. 后端单测：Domain层重点覆盖 + Application层用例编排
3. 前端单测：组件渲染 + 工具函数 + 状态管理 + 快照
4. 数据层单测：SQL逻辑 + 迁移回滚 + 约束校验
5. Mock策略：外部依赖/数据库/第三方API
6. 覆盖率分析（coverage_analyzer.py）
7. 测试质量评估（test_smell_detector.py）
8. 生成单测报告与改进建议

## 档位切换规则

| 档位 | 触发条件 | 审批要求 |
|------|---------|---------|
| L1 草稿 | 测试策略讨论、金字塔分层探索、Mock 方案对齐 | 无需评审 |
| L2 标准（默认） | 银行生产默认档，单测编写、覆盖率提升、测试质量改进 | 测试架构师评审 + 开发负责人签字 |
| L3 实施级 | 涉及资金安全/监管报送/跨系统集成/首次上线/高风险变更 | ARB/合规评审 + 深度门禁全通过 |

**自动升 L3 场景**：涉及资金类核心逻辑单测（转账/支付/清算/限额）、监管报送字段测试、跨服务事务测试、生产数据访问层测试时，自动从 L2 升 L3；L3 须通过下方「深度档位（L3 实施级）」章节的全部可计算门禁。

## 深度档位（L3 实施级）

| 档位 | 要求 |
|------|------|
| L1 | 骨架要点，用于讨论 |
| L2 | 标准评审级（银行生产默认） |
| L3 | 在L2基础上增加以下深度内容（高风险/监管/复杂集成时必用） |

### L3 工作流补充

- L3输出测试金字塔分层策略+Mock规范+覆盖率缺口分析
- 测试质量评分（独立性/断言/命名）
- 字段级缺口分析：资金类路径（转账/支付/限额）、权限校验路径、监管报送路径逐条路径在 coverage_analyzer.py 中标注 coverage<100% 的缺口
- 异常路径测试覆盖：超时、重试、熔断、降级、连接失败、并发冲突、幂等重复提交逐路径须有独立测试
- 测试坏味道深度检测：sleep 等待、直接访问私有成员、断言过弱（not None）、测试顺序依赖、共享状态污染逐项扫描（test_smell_detector.py）
- Mock 规范：外部依赖（DB/第三方/消息/时间）全部 Mock，Mock 行为可验证（verify），不 Mock 被测对象本身
- 并发安全测试：共享资源（余额/限额/库存）并发更新测试、死锁检测测试、锁粒度验证测试

### L3 质量门禁

- [ ] 关键路径100%（coverage_analyzer.py 退出码 0，all_critical_covered=true）
- [ ] 质量评分≥80（独立性/断言/命名三项评分）
- [ ] 无坏味道（test_smell_detector.py 退出码 0）
- [ ] 资金类路径无缺口（转账/支付/限额 coverage=100%）
- [ ] 异常路径测试完整（超时/重试/熔断/降级/并发冲突/幂等）
- [ ] Mock 规范达标（外部依赖全 Mock，不 Mock 被测对象）
- [ ] 并发安全测试完成（共享资源并发/死锁/锁粒度）

## 常见失败模式

| 失败模式 | 表现 | 规避措施 | 重试策略 |
|---------|------|---------|---------|
| 只测happy path | 关键路径 coverage<100%，异常路径未测 | 强制异常/边界用例 + coverage_analyzer.py | 补缺口用例后重跑分析 |
| 测试与实现耦合 | Mock 实现细节，重构即挂 | 行为驱动测试 + Mock 规范 | 重写为行为驱动后重跑 |
| 覆盖率虚高 | 行覆盖高但关键路径漏测 | 关键路径覆盖率门禁 + coverage_analyzer.py | 补关键路径用例后重跑 |
| 测试坏味道 | sleep 等待/断言过弱/顺序依赖 | test_smell_detector.py + 规范 | 修复坏味道后重跑检测 |
| Mock 不规范 | 单测依赖真实 DB/第三方 | 全 Mock + Mock 行为可验证 | 改 Mock 后重跑 |
| 测试不独立 | 测试顺序依赖/共享状态污染 | 测试隔离 + 每用例独立 setup/teardown | 加隔离后重跑 |
| 资金路径漏测 | 转账/支付/限额无并发与幂等测试 | L3 资金类路径无缺口 + 并发安全测试 | 补并发与幂等用例后重跑 |

## 升级路径

| 升级方向 | 触发条件 | 增量字段 | 回退条件 |
|---------|---------|---------|---------|
| L1 → L2 | 进入单测编写/覆盖率提升 | 测试金字塔策略、Mock 规范、覆盖率缺口分析、坏味道检测 | 评审退回，降为草稿 |
| L2 → L3 | 资金安全/监管报送/跨系统集成/首次上线 | 字段级缺口分析（资金/权限/监管路径）、异常路径测试清单、并发安全测试、Mock 行为可验证 | 风险降级或场景简化，经合规确认可回 L2 |

**人工兜底点**：L3 的关键路径清单与并发安全测试须由测试架构师与开发负责人共同确认；Agent 起草，测试架构师确认后定稿。降级须经 PM + 合规审批并记录原因。
